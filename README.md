## 🪄 Greetings, Adventurer!

I'm a self-taught programmer, aerospace-engineer-in-training and have been the 
Software/Firmware Lead at [UoN-Racing](https://github.com/uon-fs) since 2024.
My current main languages are C and Python, but I've previously worked a lot in C# and Java.

For [UoN-Racing](https://github.com/uon-fs), I oversee all development activities, overall
    about 30,000 lines of hand-written code, plus outputs from our code generation tools:
1. On-board car RTOS firmware incl. safety interlocks, powertrain, ~600v battery management (C, embedded STM32 development)
2. Realtime CAN-Bus telemetry pipeline (C, Win32/Linux)
3. Configuration and code generation tools (Python)
4. Data analysis (MATLAB)

I find it fun to consider different programming philosophies and paradigms, so I've also
    dabbled in Go, Haskell, Kotlin, Lua and [DreamBerd](https://github.com/atom-dispencer/DreamBerd),
    and even tried to [make my own language](https://github.com/atom-dispencer/Crimson-RFASM).

### 🌱 My Journey

I started learning aged 9 with the excellent book [Super Scratch Programming Adventure!](https://www.amazon.co.uk/Scratch-Programming-Adventure-Covers-Version/dp/1593274092).
    A friend and I then promptly decided to try writing my our game-engine / quasi-operating-system... thing...
    *in Scratch*, which (shockingly) never worked.
  
I started on Python a few years later to write a [Text-Based Adventure Game](https://github.com/atom-dispencer/codename_TeaBAG) (or TeaBAG for short!),
    but moved onto Java when I discovered it was possible for me to mod Minecraft!

I tried to make the [*greatest magic mod ever known to Minecraft!*](https://github.com/atom-dispencer/MagiksMostEvile)
    but, suffice to say, that did not happen.
The unending anguish of 14-year-old me trying to teach myself Gradle before I knew the meaning of the word "Closure"
    (and dealing with 1.7.10-era [Minecraft Forge](https://github.com/minecraftforge) taught me a **<ins>lot</ins>**
    about resilience.

I then worked on several Java projects, including versions of [MagiksMostEvile](https://github.com/atom-dispencer/MagiksMostEvile)
    for multiple Minecraft versions and a and a [self-updating calculator](https://github.com/atom-dispencer/VIRPTEQ-Calc)
    which I wrote because it was more interesting that `V=IR` during physics revision.

I later helped to make a [custom compiler, assembler and package manager for a virtual-computer](https://github.com/atom-dispencer/Crimson-RFASM),
    then decided to [make my own](https://github.com/atom-dispencer/iAtomSys)!
I finished the VM and started on the compiler before I was accosted by [UoN-Racing](https://github.com/uon-fs) and have been writing C ever since...

...except for a few side projects that is!

- [RGB Desklamp](https://gist.github.com/atom-dispencer/20dc906ab530efbbe35309a5eabbe17f) - A Micropython script for my homemade colour-changing lamp!
- [LED Wave Function Collapse](https://github.com/atom-dispencer/LEDWaveFunctionCollapse) - A Kotlin/Zig library to generate moving patterns on an LED matrix via the
